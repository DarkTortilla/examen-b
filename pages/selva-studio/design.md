# Selva Studio — guía visual

## Paleta de colores

| Uso | Color | HEX |
|---|---|---|
| Fondo principal | Marfil cálido | `#F5F0E6` |
| Fondo oscuro / hero | Verde bosque | `#123326` |
| Texto principal | Carbón | `#28231F` |
| Primario / CTA | Mostaza dorada | `#C9A54A` |
| Secundario | Verde salvia | `#6F806A` |
| Bordes / superficies | Arena suave | `#DED4C3` |

## Tipografía

- **Títulos:** Cormorant Garamond, 600–700.
- **Texto y navegación:** Manrope, 400–600.
- Alternativa para cuerpo: Inter.

## Dirección visual

Combinar fondos verdes profundos con superficies marfil, fotografía editorial con sombras naturales y bloques amplios de espacio en blanco. Usar tarjetas planas, divisores finos y CTAs dorados discretos. La composición debe sentirse sofisticada, artesanal y contemporánea.
